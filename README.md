## 怎么用

1. **网页看**：打开上面的 Pages 站点，左侧目录按章节，顶部可全文搜索，公式已渲染。
2. **下载进 Obsidian**：Releases 下 `welding-heat-transfer-vault.zip`，解压后用 Obsidian「打开本地仓库」指向解压目录即可。
3. **克隆**：`git clone https://github.com/2486809961-alt/welding-heat-transfer.git`

从 `焊接传热学/00 索引/焊接传热学 MOC.md` 进，按章跳转；想按问题查（"t8/5 怎么算"）走 `概念地图` / `公式总表`；想核对原文，每篇顶部有 `📄 原文：焊接传热学 张文钺.pdf#page=NN`（PDF 页 = 书页 + 4）。
