# 从瞬时点热源到 t8/5：一条推导链

> 全书看起来公式很多，其实**从式(1-26) 一路推到式(3-19) 只用了三步**：积分、求极值、作差。这篇把整条链串起来——看懂了它，第 1–3 章就只剩细节。

## 第 0 步：起点

瞬时集中点热源（半无限大，厚大焊件）：

$$T=\frac{2Q}{c\rho(4\pi at)^{3/2}}e^{-\frac{R^{2}}{4at}} \tag{1-26}$$

**这一步包含了全部物理**：热量 $Q$、热惯性 $c\rho$、扩散速度 $a$、距离 $R$、时间 $t$。

## 第 1 步：积分 → 连续热源

连续热源 = 无数瞬时热源的叠加（[[叠加原理]]）。设热源以功率 $q$ 连续作用、以速度 $v$ 沿 $x$ 移动，某一瞬时 $t'$ 给出的热量是 $q\,\mathrm{d}t'$：

$$T=\int_0^{t}\frac{2q\,\mathrm{d}t'}{c\rho\left[4\pi a(t-t')\right]^{3/2}}\exp\left[-\frac{R^{2}}{4a(t-t')}\right]$$

换成移动坐标系并令 $t\to\infty$（达到 [[准稳态温度场]]），积分收敛为 **Rosenthal 厚大焊件解**：

$$T-T_0=\frac{q}{2\pi\lambda R}\exp\left[-\frac{v}{2a}(R+x)\right] \tag{2-4}$$

> **关键技巧**：指数里的 $R+x$ 是"到热源的距离 + 沿焊接方向的分量"，它把"热源在动"编码进了公式。$x$ 取负（热源后方）时指数为正 → 温度更高，这解释了为什么焊缝后方等温线更宽。

薄板同理（二维格林函数 $1/4\pi at$ 积分后出现 $K_0$）：

$$T-T_0=\frac{q}{2\pi\lambda\delta}e^{-\frac{vx}{2a}}K_0\!\left(\frac{vR}{2a}\right) \tag{2-10}$$

## 第 2 步：求极值 → 峰值温度

某点的温度先升后降，峰值出现在 $\mathrm{d}T/\mathrm{d}t=0$ 处。代入高速热源近似 $T=\dfrac{q}{2\pi\lambda vt}e^{-r^2/4at}$ 求极值：

$$t^{*}=\frac{r_0^{2}}{4a}\quad\Longrightarrow\quad T_m-T_0=\frac{2q}{\pi e\,c\rho\,v\,r_0^{2}} \tag{3-1}$$

（薄板：$t^*=y_0^2/(2a)$，得 $T_m-T_0=\dfrac{0.242q}{c\rho v h y_0}$，式 3-2）

> 注意 $e$ 出现在分母：它是求极值时指数项带来的"自然常数"，不是经验系数。

## 第 3 步：求导 → 冷却速度

对 $T(R,t)$ 关于 $t$ 求导并整理：

$$\omega_c=\frac{\partial T}{\partial t}=2\pi\lambda\frac{(T-T_0)^{2}}{E}\quad(\text{厚板}),\qquad \omega_c=2\pi\lambda c\rho h^{2}\frac{(T-T_0)^{3}}{E^{2}}\quad(\text{薄板})$$

## 第 4 步：作差 → t8/5

把 $\omega_c=\mathrm{d}T/\mathrm{d}t$ 反解成 $\mathrm{d}t=\dfrac{E}{2\pi\lambda(T-T_0)^2}\mathrm{d}T$，从 800 ℃ 积到 500 ℃：

$$t_{8/5}=\int_{500}^{800}\frac{E\,\mathrm{d}T}{2\pi\lambda(T-T_0)^{2}}=\frac{E}{2\pi\lambda}\left[\frac{1}{500-T_0}-\frac{1}{800-T_0}\right] \tag{3-18}$$

薄板同理（$\mathrm{d}t\propto \mathrm{d}T/(T-T_0)^3$）：

$$t_{8/5}=\frac{(E/h)^{2}}{4\pi\lambda c\rho}\left[\frac{1}{(500-T_0)^{2}}-\frac{1}{(800-T_0)^{2}}\right] \tag{3-19}$$

## 第 5 步：令两式相等 → 临界板厚

$$h_{cr}=\sqrt{\frac{E}{c\rho(T-T_0)}} \tag{3-10}$$

板厚 $h\ge h_{cr}$ 用厚板式，$h<h_{cr}$ 用薄板式。

## 整条链的地图

```
(1-26) 瞬时点热源
   │ 对时间积分 + 移动坐标 + t→∞
   ▼
(2-4) Rosenthal 厚板解 ──求极值──▶ (3-1) 峰值温度
   │                          │
   │ 对 t 求导                 │ 对 T 积分
   ▼                          ▼
(3-8) 冷却速度 ──作差/积分──▶ (3-18) t8/5
   │
   │ 与薄板式相等
   ▼
(3-10) 临界板厚
```

## 每一步"偷"了什么假设（误差从哪来）

| 步骤 | 假设 | 丢掉的东西 | 后果 |
|---|---|---|---|
| 起点 (1-26) | 常物性、无潜热、半无限大、点热源 | 物性随温度变、熔化潜热、有限厚度、弧柱尺寸 | 熔合线附近温度算不准 |
| 积分 → (2-4) | $t\to\infty$（准稳态）、直线匀速 | 起弧/收弧、变速 | 焊缝两端不准 |
| 求极值 → (3-1) | 高速热源（$v$ 足够大） | 低速焊接的横向传热 | 低速焊误差大 |
| 求导 → (3-8) | 同上 | 相变潜热（会显著减慢冷却） | 冷却速度偏快 |
| 作差 → (3-18) | 区间内 $E$ 不变 | 多道焊的二次热循环 | 多层焊不准 |

> 这张表就是"为什么工程上还要修正系数 $K$、$m$"的全部理由。每一步的误差，都被后人的经验系数补上了。
