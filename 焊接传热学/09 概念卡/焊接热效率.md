# 焊接热效率（Welding Thermal Efficiency, $\eta$）

## 一句话定义

焊件真正吸收的有效功率与热源总功率之比：$\eta=q/q_0$，电弧焊 $q=\eta UI$。

## 为什么重要

它是"热源功率"与"热输入"之间的唯一转换系数。所有温度场公式里的 $q$ 都是**有效功率**，直接拿电源功率代入会系统性偏高 15%–35%。同时它决定了熔化速度，因而与生产率直接挂钩。

## 判据 / 公式 / 关键数

$$q=\eta UI \tag{1-2}$$

| 方法 | $\eta$ 量级 |
|---|---|
| 电子束、激光 | > 0.9（真空/反射损失小） |
| 埋弧自动焊 | 约 0.8 |
| 手工电弧焊 | 0.7–0.85 |
| MIG | 约 0.66–0.69 |
| 电渣焊 | 随板厚增大而升高，90 mm 板可达 **>0.8** |

## 适用条件与边界

- $\eta$ 主要取决于焊接方法、规范、材料、保护方式；同方法下电流变化、焊条药皮/焊剂不同都会改变 $\eta$。
- $\eta$ **只反映焊件吸收了多少**，不反映熔敷金属与热影响区的分配比例，因此 $\eta$ 高 ≠ 热利用合理。

## 常见误区

- 把 $\eta$ 当成"效率越高越好"：电渣焊 $\eta$ 高，但热影响区最宽。
- 用电源额定功率代替 $UI$（实际电压电流随规范变化）。
