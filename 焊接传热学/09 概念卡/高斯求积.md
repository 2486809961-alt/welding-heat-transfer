# 高斯求积（Gaussian Quadrature）

## 一句话定义

取**勒让德多项式的根**作不等距节点、按 $H_i=\frac{2}{(1-\xi_i^2)[L_n'(\xi_i)]^2}$ 加权的求积法，$n$ 点即可精确积分 $2n-1$ 阶多项式。

## 为什么重要

同样是 3 个求积点，Simpson 只精确到 3 次多项式，高斯能到 5 次——在被积函数复杂（如焊接解里的 $e^{-1/t'}$）时，**用最少的点数换最高的精度**直接等于省计算时间。本章 §4-3 的整个焊接温度场算例（图4-7、图4-8 的等温线）就是靠它在时间域上把积分求出来的。

## 判据 / 公式 / 关键数

$$\int_{-1}^{1}f(\xi)\mathrm d\xi=\sum_{i=1}^{n}H_if(\xi_i),\qquad \xi_i\ \text{为}\ L_n(\xi)\ \text{的根}$$
$$H_i=\frac{2}{\left(1-\xi_i^{2}\right)\left[L_n'(\xi_i)\right]^{2}}$$

| $n$ | $\xi_i$ | $H_i$ |
|---|---|---|
| 1 | $\pm0.5773502692$ | $1.0000000000$ |
| 2 | $\pm0.7745966692$ / $0$ | $0.5555555556$ / $0.8888888889$ |
| 3 | $\pm0.8611363116$ / $\pm0.3399810436$ | $0.3478548451$ / $0.6521451549$ |
| 4 | $\pm0.9061798459$ / $\pm0.5384693101$ / $0$ | $0.2369268851$ / $0.4786286705$ / $0.5688888889$ |

**自检**：$\sum H_i=2$（$\int_{-1}^1 1\,\mathrm d\xi=2$）。表4-1 的 OCR 曾把 $n=3$ 的中间系数打成 `1.8888888889`，用这条一秒判出。

## 适用条件与边界

- 标准区间是 $[-1,1]$；算 $[a,b]$ 上的积分必须先变换 $x=\frac{a+b}{2}+\frac{b-a}{2}\xi$，并把 $\frac{b-a}{2}$ 乘回去；
- 二维、三维用**张量积**：$\sum_i\sum_j H_iH_jf(\xi_i,\eta_j)$，各方向点数可不同（图4-3 的 $3\times3$ 配置 → 每个方向 5 阶精度）；
- $\xi_i$ **不含端点**；端点和半无限区间的对应公式是另外的族，不能混用；
- 计算量与 $n^{\text{维数}}$ 成正比，故"满足精度的前提下点数不宜过多"。

## 常见误区

- 把高斯点当等分点 / Chebyshev 点 / Simpson 点用。
- 忘记 Jacobi 因子 $\frac{b-a}{2}$，导致结果差一个长度比值。
- 记成"$n$ 点精确到 $2n$ 阶"（正确是 $2n-1$）。
- 把 $\sum H_i$ 归一化成 1（正确是 2，因为标准区间长度为 2）。
