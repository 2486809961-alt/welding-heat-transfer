# §4-1 焊接温度场的数值解法

## 核心结论

- 解析解法（Analytical solution）以**数学分析**为基础，求出函数形式的解；优点是过程清楚、有严格证明、能显式看出各因素的影响、精度高，并可用来**校核数值解**（p.84）。
- 解析解法的死穴是**只适用于简单问题**：分布热源、几何/边界不规则、物性随温度变、固态相变、边界辐射——任一出现就"很难或不可能求解，除非先简化"（p.84）。
- 数值解法以**离散数学**为基础、计算机为工具；严格性差但适应性大，上述复杂情况都能得到较好解决（p.84）。
- 常用三种：**数值积分法、有限差分法、有限元法**，以后两者为主（p.84）。
- 焊接中有限元额外受青睐的原因：温度场计算往往服务于**热应力场**，而应力场通常用有限元，两者统一可省一次数据转换（p.85）。
- 发展趋势：差分法与有限元法**互相渗透、渐趋统一**；第六章的"空间域有限元 + 时间域差分"即此（p.85）。

## 三种数值解法的对照

书中按「原理 → 优点 → 缺点」三栏给每种方法定性（p.84–85）：

| | 数值积分法 | 有限差分法 | 有限元法 |
|---|---|---|---|
| **数学基础** | 把积分区间离散成积分点，用被积函数在积分点上的数值逼近积分值 | 以**差分代微分、差商代微商**，建立以节点温度为未知量的代数方程组 | 根据**变分原理**，把热传导问题化为等价的变分问题 |
| **离散对象** | 积分域（本章是时间域） | 求解区域 → 有限个离散节点 | 求解区域 → 有限个**单元**（节点 + 单元） |
| **未知量** | 积分点上被积函数的数值 | 节点温度 | 节点温度（单元内由形函数插值） |
| **优点** | 避开"找原函数"的困难 | 线性方程组计算格式简单；方程物理意义清楚；适合形状简单规则的物体 | 单元形状可任意，适应复杂形状；可用材料分界面作单元界面；可局部加密节点；边界条件用统一观点自然包含进去；各节点精度协调 |
| **缺点** | **边界条件不好处理** | 网格多用正方形/矩形/正三角形，显得"呆板"；复杂形状或边界不易贴合 | 由变分问题表述，公式的**物理意义不像差分法那样一目了然** |

书中对两种主流方法的一句总结：**差分法注意了节点的作用，却忽视了把节点连结起来的单元；有限元法则抓住了单元的贡献**，因此具有很大的灵活性和适应性（p.84）。

两种方法精度协调性的差别也值得记：差分法要对内节点和边界节点**分别**列格式，边界节点的截断误差往往和内节点不一致；有限元法用统一观点列式，自然把边界条件包含进去，各节点精度比较协调（p.85）。

## 关键概念

- [[数值积分法]]：本章的主角，也是三种方法中最"窄"的一种——它只解决积分，不解决空间离散。
- [[有限差分法]]：第五章全书内容，与有限元并列的两大主流。
- [[高斯求积]]：数值积分法里精度/工作量比最高的一种，§4-2、§4-3 都用它。

## 工程要点

选方法的实用判据（由 p.84–85 的优缺点直接推得）：

1. **形状规则、边界简单、要快**：有限差分（网格与边界重合，格式三行就能编）。
2. **形状复杂、多材料、要局部加密、还要接着算应力**：有限元。
3. **只有时间（或某一维）上的积分算不出来**：数值积分（本章）。
4. 复杂到解析解彻底失效的情形（相变、辐射、随温度变的物性）恰恰是焊接的常态，所以"数值解为主"不是偏好而是必然。

## 易错点

- **"数值解法理论基础不如解析解法严密"不等于"结果不可靠"**。差的是推导的严密性（离散引入截断误差），不是可用性；书上同时强调解析解可作数值解的**校核**标准（p.84）。
- **数值积分 ≠ 有限元里的数值积分**。有限元中的单元积分也是数值积分，但那属于 §6；本章的数值积分是**独立的一种解法**，用在时间域。
- **差分法"物理意义清楚"、有限元"物理意义不直观"** 是书中的判断，原因是差分直接近似微分方程，有限元要绕道变分原理——考试常拿这一点做辨析题。
- 不要背成"三种方法按精度排序"。书中给的是**适应性 vs 严密性**的权衡，没有说谁更准。
