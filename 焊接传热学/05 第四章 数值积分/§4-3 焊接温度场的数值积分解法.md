# §4-3 焊接温度场的数值积分解法

## 核心结论

- 固定功率的点状/线状热源在半无限大体或大尺寸薄板上移动时，任一点任一刻的温度可由**表 4-2** 的公式求得，这些公式都含**很难积出的时间积分**，只能用数值积分（p.88）。
- 求积前必须先做**坐标变换**：高斯积分在局部坐标系 $(\xi,\eta,\zeta)$ 的**母单元**内进行，而整体求积要在整体坐标系 $(x,y,z)$ 的**子单元**上进行（p.88–89）。
- 因为是对**时间**积分，问题的实质是**一维高斯求积**：把时间域 $(0,t)$ 划成 $P$ 个子域，每个子域取 3 节点（二次单元）即可（p.89–90）。
- 形函数必须满足三个条件：本点 $N_i=1$、他点 $N_i=0$；所定义的未知量在相邻单元间**连续**；$\sum N_i=1$（p.90）。
- 形函数阶次越高 → 单元适应性越强、所需单元数越少 → 方程组阶数低、计算时间少；但运算更复杂。**存在一个最经济的阶次**，一般靠计算经验定（p.90）。
- 子域划分 + 高斯求积把不可积的解析式变成**纯加法循环**，这就是图4-9 计算框图的全部内容（p.91–92）。

### 式(4-15) 线状移动热源的温度积分式

设线状热源在大尺寸薄板上移动：热源强度 $q$［J/(cm·s)］，$q=Q/h$（$Q$ 电弧有效热功率 J/s，$h$ 板厚 cm）；沿 $X$ 轴以 $v$［cm/s］移动；取**焊接终了时**热源位置为原点（图4-6）；$t$ 为焊接过程总时间，$\tau$ 为冷却时间（由焊接终了起算）。焊接终了 $\tau$ 时刻的温度为

$$T(x,y)=\frac{q}{4\pi\lambda}\int_{0}^{t}\frac{1}{t'+\tau}\exp\left[-\frac{\bigl(x+v(t'+\tau)\bigr)^{2}+y^{2}}{4a\,(t'+\tau)}\right]\mathrm dt' \tag{4-15}$$

**符号**：$q=Q/h$ 单位长度热源强度；$\lambda$ W/(cm·℃)；$a$ cm²/s；$v$ cm/s。
**量纲检查**：$\dfrac{q}{4\pi\lambda}$ = $\dfrac{\mathrm{J/(cm\cdot s)}}{\mathrm{J/(cm\cdot s\cdot℃)}}$ = ℃；$\dfrac{\mathrm dt'}{t'+\tau}$ 无量纲 → 右侧量纲为 ℃ ✓。洁净的"温度 = 温度"关系，说明前置系数只能是 $q$ 的一次、$\lambda$ 的一次。
**物理含义**：把连续移动的热源看成**无穷多个瞬时线热源的叠加**，每个 $t'$ 时刻发出的热量经 $(t'+\tau)$ 的时间按二维高斯分布扩散，指数前的 $1/(t'+\tau)$ 正是二维瞬时线热源的衰减律（与式1-27 同族）。
**交叉校核**：令 $t\to\infty$、对 $t'$ 从 $0$ 积到 $\infty$，上式应退化为线状移动热源的**准稳态解析解**
$$T=\frac{q}{2\pi\lambda}e^{-\frac{vx}{2a}}K_0\!\left(\frac{vr}{2a}\right),\qquad r=\sqrt{x^2+y^2}$$
用 $\int_0^\infty e^{-\beta s-\gamma/s}\dfrac{\mathrm ds}{s}=2K_0(2\sqrt{\beta\gamma})$ 可验证两者完全一致——这是判断式(4-15) 系数无误的依据。

> ⚠️ 待校：积分上限在 OCR 中残缺（作 "$t$"，也可能为 $t+\tau$）；指数内的 $x+v(t'+\tau)$ 与分母 $t'+\tau$ 可辨认，但 $x$、$y$ 的原点取法（焊接终了时热源位置）决定了 $x$ 的符号。

### 式(4-16) 把时间域分成 $P$ 个子域

若每个子域取三个节点（三节点二次单元）：中间节点整体坐标 $t_i$，前后两节点为 $t_i-\dfrac{\Delta t}{2}$、$t_i+\dfrac{\Delta t}{2}$，节点间时间步长 $\Delta t$。把时间域 $(0,t)$ 划分为 $P$ 个子域后，式(4-15) 写成

$$T(x,y)=\sum_{p=1}^{P}\frac{q}{4\pi\lambda}\int_{t'_{p-1}}^{t'_{p}}\frac{1}{t'+\tau}\exp\left[-\frac{\bigl(x+v(t'+\tau)\bigr)^{2}+y^{2}}{4a(t'+\tau)}\right]\mathrm dt' \tag{4-16}$$

**含义**：把大区间上的积分拆成 $P$ 个小积分之和。每段的被积函数光滑、变化尺度小，才适合低阶插值。

### 式(4-17) 用形函数做坐标变换

把整体坐标系内子单元中任一点的坐标 $t'$，通过形函数用节点坐标 $t_i$ 表示：
$$t'=\sum_{i=1}^{3}N_i(\xi)\,t_i \tag{4-17}$$
三节点二次单元的形函数（局部坐标 $-1\le\xi\le1$，节点 $\xi=-1,0,1$）：
$$N_1=\frac{\xi(\xi-1)}{2},\qquad N_2=\frac{\xi(\xi+1)}{2},\qquad N_3=1-\xi^{2}$$
**自检**：$\sum N_i=\dfrac{\xi^2-\xi+\xi^2+\xi}{2}+1-\xi^2=\xi^2+1-\xi^2=1$ ✓（满足条件 3）。
**自检**：$\xi=-1$ 时 $N_1=1,N_2=0,N_3=0$；$\xi=0$ 时 $N_3=1$；$\xi=1$ 时 $N_2=1$ ✓（满足条件 1）。
**等距特例**：三节点等距时 $t'=t_i+\dfrac{\Delta t}{2}\xi$，$\mathrm dt'=\dfrac{\Delta t}{2}\mathrm d\xi$ —— 这就是式(4-18) 里那个 $\frac{\Delta t}{2}$ 的来源。

### 式(4-18) 代入后改写为 $\xi$ 上的积分

$$T(x,y)=\sum_{p=1}^{P}\frac{q}{4\pi\lambda}\cdot\frac{\Delta t}{2}\int_{-1}^{1}\frac{1}{\sum N_i t_i+\tau}\exp\left[-\frac{\left(x+v\left(\sum N_i t_i+\tau\right)\right)^{2}+y^{2}}{4a\left(\sum N_i t_i+\tau\right)}\right]\mathrm d\xi \tag{4-18}$$

**量纲检查**：$\dfrac{\Delta t}{2}\mathrm d\xi$ 自带时间量纲，与式(4-16) 的 $\mathrm dt'$ 对应 ✓；其余因子与(4-15) 同。
**含义**：积分区间从"任意长度的时间段"变成**标准的 $[-1,1]$**，从此可以直接套 §4-2 的表4-1。

### 式(4-19) 对每个子域做高斯求积

$$T(x,y)=\sum_{p=1}^{P}\frac{q}{4\pi\lambda}\cdot\frac{\Delta t}{2}\sum_{g=1}^{n}H_g\,\frac{1}{\sum N_i(\xi_g)t_i+\tau}\exp\left[-\frac{\left(x+v\left(\sum N_i(\xi_g)t_i+\tau\right)\right)^{2}+y^{2}}{4a\left(\sum N_i(\xi_g)t_i+\tau\right)}\right] \tag{4-19}$$

**符号**：$n$ 高斯求积点数目；$H_g$ 求积加权系数（查表4-1）；$\xi_g$ 高斯点坐标。
**用法**：设定 $n$ 后，查表4-1 得 $H_g$ 与 $\xi_g$，分别代入式(4-17) 与式(4-19)，即可解出 $T(x,y)$（p.91）。
**量纲检查**：同(4-18)，$H_g$ 无量纲 ✓。

### 形函数的一般形式（含单元形状）

书中先给出局部坐标系中母单元的形函数（p.89–90）：

**（1）线性单元（2 节点）**
$$N_1=\frac{1-\xi}{2},\qquad N_2=\frac{1+\xi}{2}$$

**（2）二次单元（3 节点）**
$$N_1=\frac{\xi(\xi-1)}{2},\qquad N_2=\frac{\xi(\xi+1)}{2},\qquad N_3=1-\xi^{2}$$

**（3）三次单元（4 节点）**，节点 $\xi=-1,-\frac13,\frac13,1$：
$$N_1=\frac{1}{16}(1-\xi)(9\xi^{2}-1),\qquad N_2=\frac{9}{16}(1-\xi^{2})(1-3\xi)$$
$$N_3=\frac{9}{16}(1-\xi^{2})(1+3\xi),\qquad N_4=\frac{1}{16}(1+\xi)(9\xi^{2}-1)$$

**自检（三次单元）**：
$\sum N_i=\frac{1}{16}(9\xi^2-1)\cdot2+\frac{9}{16}(1-\xi^2)\cdot2=\frac{9\xi^2-1+9-9\xi^2}{8}=1$ ✓
$\xi=-1$：$N_1=\frac{1}{16}\cdot2\cdot8=1$，其余为 0 ✓；$\xi=-\frac13$：$N_2=\frac{9}{16}\cdot\frac89\cdot2=1$ ✓；$\xi=\frac13$：$N_3=1$ ✓；$\xi=1$：$N_4=1$ ✓

**形函数的三个条件**（p.90）：
1. 在节点 $i$，$N_i=1$；在其他节点，$N_i=0$；
2. 用它所定义的未知量在相邻单元之间是**连续**的；
3. $\sum N_i=1$（保证能表示常数场/刚体位移）。

**坐标转换**：一维问题简单，
$$x=\sum N_i(\xi)\,x_i$$
其中 $N_i(\xi)$ 是局部坐标表示的形函数，$(x_i)$ 是节点 $i$ 的整体坐标。

## 关键概念

- [[高斯求积]]：本节把它套在"时间"这个一维区间上，是因为焊接解的时间积分没有原函数。
- [[数值积分法]]：母单元/子单元、形函数、Jacobi 因子 $\frac{\Delta t}{2}$，都是"把积分搬到标准区间"的技术细节。
- 母单元（master element）：局部坐标 $(\xi,\eta,\zeta)$ 中形状固定的标准单元（如 $-1\le\xi\le1$ 的线性单元）。
- 子单元（sub-element）：母单元经坐标转换后在整体坐标系 $(x,y,z)$ 中得到的不同长度/形状的曲线单元（图4-5）。

## 工程要点

- **算例 1（图4-7，单丝单面埋弧自动焊）**：对接拼板 $8000\sim12000\times3000\times16$ mm，船用低碳钢，单面焊一次焊成。计算取
  $\dfrac{q}{h}=17290\ \mathrm{J/(cm\cdot s)}$，$v=0.8\ \mathrm{cm/s}$，$a=0.08\ \mathrm{cm^2/s}$，$\lambda=0.375\ \mathrm{J/(cm\cdot s\cdot℃)}$，$c=0.679\ \mathrm{J/(g\cdot℃)}$，$\rho=7.68\ \mathrm{g/cm^3}$，初温 $0\ ℃$（p.91）。
- **算例 2（图4-8，双丝单面埋弧自动焊）**：$q_1/h=q_2/h=12750\ \mathrm{J/(cm\cdot s)}$，$v=0.75\ \mathrm{cm/s}$（p.92）。
- **图4-9 计算框图**的流程即为程序结构：开始 → 输入原始数据 →（温度场编号、焊丝编号、校正电位）→ 判断是否加热 → 时间域离散（确定节点时间）→ 节点坐标循环 → 加热时间循环 → 计算积分值 → 计算节点温度 → 节点温度叠加 → 输出节点温度 → 结束（p.92）。
- **结论性事实**：3 节点二次单元 + 高斯求积就足以给出可用的焊接等温线图——精度不是靠"密"，而是靠"阶"。

## 易错点

1. **别忘了 Jacobi 因子 $\dfrac{\Delta t}{2}$**。式(4-16)→(4-18) 的这一步最容易漏，漏了量纲立刻不对（右侧变成 $\mathrm{℃\cdot s^{-1}}$ 类的怪东西）。
2. **形函数的下标次序与节点坐标绑定**。三次单元的 $N_2$ 对应 $\xi=-\frac13$，$N_3$ 对应 $\xi=+\frac13$；OCR 里这两个常被互换，须用"本点为 1"逐个验算。
3. **$\sum N_i=1$ 不是可选项**，它保证单元内能表示常数温度场；不满足的"形函数"是错的。
4. **$\tau$ 的起点是焊接终了**，$t$ 是焊接总时间；两个时间别混（混了积分限就错）。
5. **算例参数自洽性**：$\lambda/(c\rho)=0.072$ 而书中给 $a=0.08\ \mathrm{cm^2/s}$，差 11%，代入前须统一（见章笔记待校）。
