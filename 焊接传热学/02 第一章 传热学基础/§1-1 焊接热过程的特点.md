# §1-1 焊接热过程的特点

## 核心结论

- 焊接热过程比热处理热过程复杂，差别集中在**三点**：局部集中性、瞬时性、热源运动性（p.4）。
- 三点合起来导致的结果是：加热与冷却**极不均匀**、温度变化**极快**、过程处于**准稳定状态**。

## 三个特点

### 1. 局部集中性

熔化焊时热源只作用在接头部位，极短时间内把局部加热到熔化，形成焊接接头。
→ 焊件**不是整体加热**，因此加热与冷却极不均匀，这是产生**应力、变形、裂纹**的根源。

### 2. 瞬时性

高度集中热源下加热速度极快，**电弧焊可达 1500 ℃/s 以上**。
→ 大量热能在极短时间内输入，与热处理"整体缓慢加热"有本质区别。热物性随温度剧烈变化、相变潜热、非平衡组织等问题都由此而来。

### 3. 热源运动性

热源移动使受热区域不断变化：热源接近某点 → 该点迅速升温；热源远离 → 该点冷却降温。
→ 传热过程本质上是**准稳定状态**（Quasi-Stationary State，p.4）。

## 为什么这三条决定全书结构

| 特点   | 带来的困难               | 书中的应对                    |
| ---- | ------------------- | ------------------------ |
| 局部集中 | 三维、二维、一维导热并存，几何边界复杂 | 用**点/线/面热源**理想化（§1-4、§2） |
| 瞬时   | 物性随温度剧变、有相变潜热，方程非线性 | 解析解假定常物性；数值解处理非线性（§6）    |
| 运动   | 温度场随热源平移，不能当稳态处理    | 引入**移动坐标系**得准稳态解（§2）     |

## 易错点

- "瞬时性"指的是**热源把热能瞬时给入**这一理想化（瞬时热源），与真实电弧的连续加热不是一回事；真实过程要用叠加原理把连续热源看成无数瞬时热源（§1-8）。
- "准稳定"不等于"稳定"：温度场整体形态不变，但材料上每一点的温度仍在变。
