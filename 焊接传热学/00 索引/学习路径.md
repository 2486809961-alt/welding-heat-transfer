# 学习路径与复习清单

## 一、三条阅读路线（按目的选）

### 路线 A：理论主线（想吃透解析解，约 2 周）

```
绪论 → §1-1 ~ §1-8（打地基）→ §2-1（厚大焊件 Rosenthal）
    → §2-2（薄板，K0 函数）→ §2-4（极限饱和/简化式）
    → §3-2（热循环参数解析）→ §3-3（t8/5）
```

关键卡点：**§1-7 三个瞬时解** 与 **叠加原理**。这两个不熟，第 2 章全部公式都只能背不能推。

### 路线 B：数值主线（要建模/仿真，约 2 周）

```
§1-5（方程）→ §1-6（边界条件）→ 第 4 章（数值积分）
    → 第 5 章（差分：显式/隐式、稳定性）
    → 第 6 章（有限元：变分/权余值 → 网格 → 相变潜热 → 热源模型）
```

关键卡点：**稳定性条件**与**相变潜热的等效热容处理**。这两处是从"能算"到"算对"的分水岭。

### 路线 C：工程应用（要在现场用，约 3 天）

```
§1-2（线能量）→ §1-4（板厚判据、材料物性）
    → §2-4（简化公式）→ §3-1 ~ §3-4（热循环、t8/5、SHCCT）
    → §7（实测：热象法）
```

关键收获：给定材料+板厚+线能量，能估算**峰值温度、t8/5、热影响区宽度**，并据此定预热与层间温度。

## 二、必须先建立的 6 个直觉

1. **热输入决定一切**：$q/v$ 定形状，$\eta$ 定大小。
2. **维数决定公式**：点/线/面 ↔ 三维/二维/一维 ↔ 指数/$K_0$/$\Phi$。
3. **厚薄是相对判据**：25 mm 碳钢 / 20 mm 不锈钢以上算"厚大"，8 mm / 5 mm 以下算"薄板"。
4. **$a$ 大 ≠ 冷得快**：$a$ 大是热量摊得开、峰值低、冷得慢。
5. **准稳态看形状，不看温度**。
6. **误差来自五条假定**：常物性、无潜热、无限尺寸、热源集中、无表面散热。

## 四、高频易错点（考试/答辩常被问）

| 错误 | 正确 |
|---|---|
| 用 SI 数据套书中公式 | 书中全是 cm 制，$\lambda$ 换算差 100 倍 |
| 半无限大漏乘 2 | (1-26) 有系数 2，(1-25) 没有 |
| 认为准稳态=温度不变 | 是场的形状不变 |
| 叠加时共用同一个 $t$ | 各热源时间独立起算 |
| $\lambda$ 小 → 等温线范围小 | 反了，$\lambda$ 小热量堆在附近，范围**大** |
| 把电源功率当有效功率 | 必须乘 $\eta$ |
| 差商方向搞反 | 前向/后向/中心要对应边界位置 |
