第二章 焊接温度场及其数学模型

一句话

把焊件按厚大焊件 / 薄板 / 细棒分成三类（点 / 线 / 面热源），用解析解给出任意点的温度场。

三条主线（务必分清）：

焊件 热源模型 导热维数 饱和温度 T_op 的衰减
厚大焊件（半无限大体） 点状热源 3D ∝ 1/R
薄板 线状热源 2D ∝ K₀(·)（对数型）
细棒 面状热源 1D ∝ 指数衰减

核心结论（本章必须记住的 8 条）

  1. 连续作用热源分三类：连续固定热源（v=0，相当于补焊缺陷）、正常速度连续移动热源（正常焊接/堆焊）、高速移动热源。三者的温度场特征完全不同（p.27）。
  2. 厚大焊件点状连续固定热源：T_op = q/(2πλR)，温度只与 R 成反比、与时间无关；R→0 时理论上 T→∞，实际只到金属熔点与沸点之间（p.27–28）。
  3. 点状连续移动热源：进入 极限饱和状态（t→∞）后温度场是准稳定的，"和热源一起移动，就好像火车带着列车一样"；公式为 T = q/(2πλR)·exp[−(v/2a)(R+x)]（p.29，式 2-4）。
  4. 热源前后不对称：厚大焊件 X 轴上，热源后面各点温度与焊速无关（T = q/(2πλR)），前面各点陡降（多一个 exp(−vx/a) 因子）。薄板则相反——前面梯度大、后面梯度小，且后面温度仍与焊速有关（p.31、p.33）。
  5. 薄板/细棒必须计表面散热：厚大焊件表面散热可忽略，薄板、细棒不能忽略，公式中多乘 exp(−δt)，散温系数 δ 薄板为 2α/(cρh)、细棒为 αL/(cρF)（p.24–25、p.28–30）。
  6. 极限饱和温度可以查图算：用无因次量 Ω₁ = 4πλaT/(qv)（厚大）或 Ω₂ = 2πλhT/q（薄板），由图 2-10、图 2-12 读出 p 或 P，再由 R = 2ap/v 或 r = 2aP/v 反算等温线半径（p.34–37）。
  7. 有限时间用饱和系数 ψ 修正：T(t) = ψ(β,τ)·T_op，ψ 由 β、τ 查图 2-14；断火（冷却）用正负热源叠加 T = T_op[ψ(t) − ψ(t−t_k)]（p.37–40）。
  8. 实际板厚的影响有上限：板厚大到一定程度就不再影响传热（相当于半无限大体），这个转折板厚叫 临界板厚 h临，由冷却速度公式求出；厚大焊件与薄板的分界线不是固定数值，取决于材质、线能量和预热温度（p.41）。

符号约定（全章通用）：$q$ 热源有效功率 J/s；$\lambda$ 导热系数 J/(cm·s·℃)；$a$ 热扩散率 cm²/s；$c\rho$ 容积比热容 J/(cm³·℃)；$R$ 距热源距离 cm；$h$ 板厚 cm；$F$ 细棒断面积 cm²；$v$ 焊速 cm/s；$T$ 均为温升（已扣除初始温度 $T_0$）。

工程含义

  1. 厚大焊件看 $1/R$，薄板看 $K_0$，细棒看指数——决定"热影响区有多宽"的首先是焊件厚度与线能量的相对关系，不是电流电压本身。
  2. 焊速提高使热源前方温度陡降、后方温度相对滞留，这是焊缝成形"前坡陡、后坡长（鱼尾状）"、以及后热区晶粒粗大的直接热学原因（p.31、p.33）。
  3. 补焊（v=0）比正常焊接更容易在热源周围形成长时间高温，因为 T_op = q/(2πλR) 与焊速无关，没有"移动带走热量"的冷却效应（p.27–29）。
  4. 薄板/细棒的表面散热不可忽略：板越薄、棒越细，δ 越大，温度峰值越低、冷却越快——所以薄板焊接要降低热输入才不会烧穿（p.24–25）。
  5. 中厚板（低碳钢手工电弧焊 8–24 mm）上下表面温差可达 200 ℃ 量级（例 5 中 1030 ℃ 与 815 ℃），这是角变形与未熔透的重要热学根源（p.42–43）。
  6. 高速焊（低碳钢 v > 36 m/h ≈ 1 cm/s）可用瞬时线源近似，等温线近似为以焊道为轴的圆柱面族，热影响区窄（p.45）。

易错点 / 常考辨析

  1. 厚大焊件 vs 薄板公式何时用：判据不是"板有多厚"，而是 临界板厚——由材质、线能量、预热温度共同决定的分界板厚。20 mm 低碳钢在例 5 的规范下已接近厚大焊件（p.43）。
  2. "点状/线状/面状"说的是热源模型的维数，不是焊件的形状：厚大焊件→半无限大体→点状热源（3D）；薄板→线状热源（2D）；细棒→面状热源（1D）。热源维数越低，温度随时间衰减越慢（T ∝ t^(−3/2)、t^(−1)、t^(−1/2)）（p.23）。
  3. 固定热源与移动热源的饱和温度不同：v=0 时 T_op = q/(2πλR)（式 2-2、2-5 完全相同）；v≠0 时多出 exp[−(v/2a)(R+x)]。不要漏掉指数项，也不要把它写成 exp(−vR/2a)（错：R 与 x 不能混）。
  4. x 的正方向：书中 x 正方向指向热源前方（焊速方向）。写成 exp[−(v/2a)(R+x)] 时，热源前方 x>0 → 温度低；热源后方 x=−R → 指数为 0 → 与固定热源相同。方向搞反，结论正好相反。
  5. 薄板公式中 $\lambda h$ 是一个整体（"单位宽度导热系数"），量纲为 J/(s·℃)；漏掉 h 会把温度算大几倍。
  6. ψ 是"饱和系数"，不是效率：ψ∈[0,1]，含义是该时刻温度占饱和温度的比例；与电弧有效系数 η 完全是两件事（p.37）。
